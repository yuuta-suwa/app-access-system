# 利用者向け使い方

1. 「Google でログイン」を押します。初回は「管理者の承認待ちです」と表示されます。承認後に「状態を再確認」を押してください。
2. ホームには、あなたが使える分類と **SELF（自分専用）** だけが表示されます。
3. 分類を選ぶ →「何がしたいですか？」から目的を選ぶ → アプリを選んで「アプリを開く」。アプリは別タブで開きます。
4. よく使うアプリは「SELF に保存」。
5. 上部の検索で、やりたいこと・アプリ名から探せます（あなたが使える範囲だけが対象）。

## SELF

- 「名前＋URL」だけで自分用のリンクを登録できます（https:// のみ）。用途メモ・フォルダ・並び替えは任意。
- 同じ Google アカウントなら、スマホと PC で同じ内容が表示されます（「最新に更新」で再読み込み）。
- 他の人（管理者を含む）は画面からあなたの SELF を見ることはできません。
- パスワード、API キー、ログイン用の秘密 URL は登録しないでください（秘密情報らしき URL には警告が出ます）。
- 保存した共通アプリが利用できなくなった場合は「アクセスできない項目」と表示されます。削除してください。

## 困ったとき

- 「このページは利用できません」：URL が違うか、あなたの利用範囲外です。
- 「ご利用を停止しています」：管理者にお問い合わせください。
- 「セッションの有効期限が切れました」：もう一度ログインしてください。
